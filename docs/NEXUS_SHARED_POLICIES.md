# Nexus Wave Technologies — Shared Product Policies

This directory is the canonical policy source for the Nexus ecosystem.

Products covered:
- Nexus Plus
- Geeta Nexus

## Shared principles

- User-facing privacy and legal language should be clear and accessible.
- Authentication for the website uses Supabase Auth.
- Product-specific permissions and sensitive Android capabilities must be disclosed in the relevant product privacy documentation.
- Security controls must follow the platform rules of the target platform.

## Website

The public website is an Astro application under `artifacts/web`. Its deployment configuration is in the repository-level `vercel.json`.
